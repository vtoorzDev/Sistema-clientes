#  Sistema de Gerenciamento de Clientes (Java + MySQL)

Sistema interativo executado **via terminal**, desenvolvido em **Java** com persistência em banco de dados **MySQL** utilizando **JDBC** e a arquitetura **DAO (Data Access Object)**.

---

##  Funcionalidades (CRUD)

- **Menu Interativo via Terminal:** Navegação por terminal de comando via opções numéricas.
- **Cadastrar Cliente:** Registro de novo cliente no banco de dados MySQL.
- **Read / Buscar Cliente:** Consulta individual por ID via terminal com exibição detalhada dos dados.
- **Read / Listar Todos:** Listagem de todos os clientes cadastrados exibidos no console.
- **Deletar Cliente:** Remoção de cliente por ID via terminal.

---

##  Tecnologias Utilizadas

* **Linguagem:** Java
* **Interface:** Terminal / Linha de Comando (CLI)
* **Banco de Dados:** MySQL
* **Conectividade:** JDBC (Java Database Connectivity) & MySQL Connector
* **Padrão de Arquitetura:** DAO (Data Access Object)
